## 📖 Overview

This portfolio presents my background as a **B.Tech Computer Science student** at Amal Jyothi College of Engineering, Kerala. It highlights my technical skills, academic projects, education, and contact information through a streamlined, single-page layout designed to offer an immersive user experience.

## 🚀 Features

- **Immersive Visuals**: Animated parallax Earth background paired with a modern dark space theme.
- **Glassmorphism UI**: Sleek, frosted-glass card designs for a premium feel.
- **Dynamic Project Showcase**: Built-in category filtering (All / Web Dev / Data Analytics) to easily navigate through my work.
- **Interactive Contact Section**: Integrated Google Forms backend with a custom success modal for seamless communication.
- **Fully Responsive**: Optimized layout for desktop, tablet, and mobile devices.
- **Smooth Navigation**: Custom smooth scrolling for an elegant browsing experience.
- **Direct Resume Access**: One-click PDF download link for potential employers.

## 🗂️ Sections

1. **Home** — Hero section featuring a brief introduction and intuitive call-to-action buttons.
2. **About** — Personal summary, interests, and educational background.
3. **Skills** — Key technical proficiencies spanning across software development and data analytics.
4. **Projects** — Detailed project highlights with interactive category filtering.
5. **Contact** — Direct contact details, social media links, and a functional contact form.

## 💻 Local Setup

This is a static website, so no complex build tools or dependencies are required. To view the project locally:

1. Clone the repository:
   ```bash
   git clone https://github.com/don8891/portfolio.git
   ```
2. Navigate to the project directory:
   ```bash
   cd portfolio
   ```
3. Open `index.html` directly in your favorite web browser, or serve it using a local HTTP server:
   ```bash
   python -m http.server 8000
   ```
